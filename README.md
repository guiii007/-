# 内容迁移

一个 Windows 本地摘录工具：选中文字，右键点“内容迁移”，附上备注，将原文、时间、标题和出处追加到桌面的 `内容迁移.txt`。

![内容迁移图标](assets/content-mover.png)

## 使用

下载仓库中的 `downloads/内容迁移-Windows.zip`，解压到固定目录，双击 `内容迁移.exe`。需要 Windows 10/11 x64 和系统自带的 .NET Framework 4.x，无需安装 Python、Node 或第三方运行库。

1. 选中文字，点击鼠标右键。
2. 当 Windows 辅助功能接口能确认文字选区时，原菜单旁会显示“内容迁移”按钮。空选区时不显示。
3. 核对标题与出处，输入备注，点击“保存到 TXT”。每次追加，不覆盖原有记录。

快捷键 **Ctrl+Alt+M** 可直接触发摘录。某些应用不暴露选区状态时，右键按钮会隐藏；可以先 **Ctrl+C**，再按快捷键。自动读取失败时，兼容模式会展示剪贴板文字，必须核对并勾选确认后才能保存。

## 来源和标题

- Word：尝试获取文档路径、页码和选区字符位置。
- 浏览器：尝试获取地址栏 URL；配套 Chrome / Edge 扩展能将入口放进浏览器右键菜单，并提供页面 URL。
- AI 客户端：记录应用及窗口标题。ChatGPT 桌面端会尝试读取当前聊天的选中导航项或专门的标题控件；没有公开可识别标题时，保存窗口要求填写聊天标题，避免记录只有“ChatGPT”。
- 所有标题和出处均可在保存前修改。无法取得 URL / 路径时会明确标注，不会编造链接。

TXT 保存应用提供的纯文本，保留字符串中的空格、换行、制表符和 Unicode；字体、图片和富文本格式不属于 TXT。工具不改写原文，但应用自身的复制行为可能影响排版。

## 设置

工具运行后，双击启动快捷方式打开设置；也可右键通知区域的工具图标，选择“设置 / 开机自启…”。自启开关立即生效，默认关闭。托盘菜单还可更改保存文件、关闭右键按钮或退出工具。

## 浏览器扩展

先启动桌面程序，让它生成配对配置。然后在 Edge / Chrome 的扩展管理页面开启开发人员模式，选择“加载解压缩的扩展”，选中解压目录下的 `browser-extension` 文件夹。

扩展只请求用户点选的当前页面选区，使用配对令牌发到 `127.0.0.1:19339`。不会上传笔记到服务器。

## 开发

在 Windows PowerShell 中执行：

```powershell
.\build.ps1
```

构建脚本使用 Windows .NET Framework 的 C# 编译器，同时生成透明 PNG 和多尺寸 ICO。

```powershell
Start-Process .\内容迁移.exe --self-test -Wait
Start-Process .\内容迁移.exe --render-test -Wait
node .\test-extension.cjs
```

测试覆盖原文保留、追加写入、剪贴板兼容核对、聊天标题、开机自启，以及浏览器桥接的授权和来源限制。`--integration-test` 是可选的真实桌面测试，只操作专用示例窗口；跨应用兼容性需在实际客户端确认。

配置 `config.json`、扩展配对文件 `pairing.js`、个人摘录和本机诊断不属于发布内容。请勿把配对令牌上传到公开仓库。更新或卸载不会删除桌面摘录文件。
