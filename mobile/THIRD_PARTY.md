Windows QR encoding uses ZXing.Net 0.16.9 (Apache-2.0): https://github.com/micjahn/ZXing.Net

Original license: https://www.apache.org/licenses/LICENSE-2.0

Java and Android SDK are build tools only and are not packaged inside the installed applications.
